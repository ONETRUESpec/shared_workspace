# Shared Workspace

## Projects

- `multitool-forge-mod/` — Minecraft Forge mod for Minecraft 26.3 / Forge 66.0.4: a pickaxe, axe and shovel
  combined into one tool, for every vanilla tool material. See its README for crafting and build instructions.
- `magnet-forge-mod/` — Minecraft Forge mod for Minecraft 26.3 / Forge 66.0.4: a toggleable magnet that pulls
  dropped items and experience orbs towards you from up to 10 blocks away (configurable). See its README.
- `compressed-blocks-forge-mod/` — Minecraft Forge mod for Minecraft 26.3 / Forge 66.0.4: compress nine blocks into
  one, nine tiers deep, for dirt, cobblestone, stone, sand, gravel, netherrack and more. See its README.
- `inventory-sorter-forge-mod/` — Minecraft Forge mod for Minecraft 26.3 / Forge 66.0.4: middle-click (Pick Block)
  any slot to sort and stack that inventory or chest. See its README.
